三、技术选型要点

语言构成

95% C：内核核心 / 驱动 / 系统组件 / 上层应用

5% 汇编：启动入口 / MMU / 中断上下文 / SBI / 特权级切换

工具链与环境

  • 编译器：riscv64-unknown-elf-gcc
  • 目标：rv64gc / lp64d · 裸机 freestanding
  • 零系统依赖 · 零库依赖 · 纯自研内核
  • 构建：Makefile → netrdorvos.elf / .bin

禁止项

  • ✕ Rust（裸机 RV64 适配繁琐）
  • ✕ C++（无标准库 · 虚函数开销）
  • ✕ Python / 脚本（需运行时）
  • ✕ Go / Java（不支持裸机 RV64）
